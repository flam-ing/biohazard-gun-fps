# BIOHAZARD SMART-GUN (4인 협동)

스마트폰을 총처럼 들고 PC 화면을 겨눠 좀비를 막는 브라우저 게임이에요. 앱 설치 없이 폰 브라우저의 방향 센서로 조준해요. 최대 4명이 함께 할 수 있어요.

- PC 화면: https://biohazard-gun-fps.onrender.com
- 폰 컨트롤러: https://biohazard-gun-fps.onrender.com/controller.html (PC 화면의 QR을 찍어도 돼요)

## 하는 방법

1. PC에서 게임 화면을 열고, 화면을 한 번 클릭해 소리를 켜요.
2. 폰 카메라로 QR을 찍고 "시작하기"를 눌러요. iPhone은 "동작 및 방향 접근"을 허용해요.
3. 폰 윗부분으로 PC 화면 가운데 표적을 겨누고, 폰 화면을 아무 곳이나 눌러요. 그 방향이 내 화면 가운데가 돼요.
4. 로비에서는 연습 사격을 할 수 있어요. 모두 준비되면 누구든 폰의 "게임 시작"이나 PC의 "게임 시작"(Enter)을 눌러요.
5. 게임 중에 들어온 사람도 가운데만 맞추면 바로 함께 싸워요.

## 폰 조작

| 동작 | 하는 일 |
| --- | --- |
| 화면 누르기 | 사격 (아래로 쓸면 쏘지 않고 장전만 해요) |
| 화면을 아래로 쓸기, 아래쪽 "장전" 누르기 | 장전 |
| 총구를 아래로 확 내렸다 올리기 | 장전 |
| 탄이 없을 때 누르기 | 장전 |
| 오른쪽 위 설정 버튼 | 감도, 무기(권총/샷건/매그넘), 좌우 반대로, 가운데 다시 맞추기 |

감도, 무기, 탄약, 점수, 가운데 위치는 플레이어마다 따로예요. 한 사람이 가운데를 다시 맞춰도 다른 사람 조준은 그대로예요.

## PC 키

| 키 | 하는 일 |
| --- | --- |
| Enter | 로비에서 게임 시작 |
| Esc | 게임 중 참가 QR 열기/닫기 (여기서 로비로 돌아갈 수도 있어요) |
| C | 모든 폰에 "가운데 다시 맞추기" 요청 |

## 연결 규칙

- 들어온 순서대로 1P(빨강), 2P(파랑), 3P(노랑), 4P(초록)가 돼요.
- 5번째 폰은 "4명이 꽉 찼어요" 화면이 나와요.
- 폰을 새로고침하거나 화면이 잠깐 꺼져도 15초 안에 돌아오면 같은 자리로 들어가요. 무기, 탄, 점수도 그대로예요. 가운데만 다시 맞추면 돼요.
- PC 화면을 새로고침해도 폰은 그대로 연결돼 있고, 감도와 가운데 상태를 다시 보내요.
- PC 게임 화면은 한 곳에서만 돌아가요. 다른 PC나 탭에서 새로 열면 그쪽이 이어받고, 예전 화면에는 "다른 PC 화면에서 게임을 열었어요"가 떠요.
- 아무도 연결돼 있지 않은 채로 20초가 지나면 로비로 돌아가요.

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 열어요. 폰 센서는 https 주소에서만 동작하니, 폰으로 해 보려면 Render 같은 https 주소에 배포해서 써요.

## 폰 없이 검사하기

```bash
npm test                # 서버 라우팅 검사 + Chrome으로 화면 로직 검사
npm run test:server     # 서버 검사만
npm run screens         # 검사하면서 screenshots/ 폴더에 화면을 저장
```

`scripts/sim-players.js`가 가짜 폰 4~5대를 연결해서 자리 배정, 이벤트 전달, 플레이어별 가운데·탄약·감도, 5번째 폰 거절, 재접속(폰 새로고침 뒤 조준·무기·탄 유지), PC 화면 하나만 동작, 손떨림 필터, 조준 전송 누락, 장전 오작동, 쓸어서 장전할 때 오발, Three.js CDN 대체, GPU 메모리 정리를 확인해요. Chrome 위치가 다르면 `CHROME_PATH`로 알려 주세요.

## 구조

- `server.js`: Express + Socket.IO. 폰 이벤트는 PC 화면(`displays` 방)으로만 보내고, PC 화면이 보내는 탄약 정보는 해당 자리(`slot:N` 방) 폰에만 보내요.
- `public/index.html`: PC 화면 (Three.js 3D, HUD, 플레이어별 조준 필터).
- `public/controller.html`: 폰 컨트롤러 (방향 센서, 사격, 장전, 설정).
